# School Bus Route Management System

CSE326 CA Project (Section K4P26TD)

## Team
- Smriti Rani (12624274)
- Shreya Mahapatra (12625257)

## About
A web-based platform for schools to manage buses, drivers, routes, stops and student assignments in one place.

## Features
- Admin login and logout
- Add and delete buses, drivers, routes and students
- Student assignment with a bus capacity check
- Search in every table
- Dashboard with live counts
- Responsive design

## Technologies
HTML, CSS, JavaScript (data saved with localStorage)
